# Requirements: JoinQuant API & Strategy Knowledge Base

**Defined:** 2026-03-22
**Core Value:** AI models can query accurate JoinQuant API documentation so they write correct JoinQuant code on the first try.

## v1 Requirements

### Scraping

- [x] **SCRP-01**: System can log in to JoinQuant via Playwright with stored credentials
- [x] **SCRP-02**: System persists login session to avoid repeated authentication
- [x] **SCRP-03**: System scrapes all strategy names, categories, and code from "经典策略学习" sidebar
- [x] **SCRP-04**: System scrapes API docs from 获取股票数据 page
- [x] **SCRP-05**: System scrapes API docs from 获取单季度年度财务数据 page
- [x] **SCRP-06**: System scrapes API docs from 上市公司概况 page
- [x] **SCRP-07**: System scrapes API docs from 获取融资融券标的列表 page
- [x] **SCRP-08**: Scraper can be re-run idempotently without data duplication

### Database

- [x] **DB-01**: SQLite schema stores API docs with function name, parameters, return type, description, and examples
- [x] **DB-02**: SQLite schema stores strategy code with name, category, code content, and description
- [x] **DB-03**: Parameters stored as structured data (searchable per-parameter, not blob)
- [x] **DB-04**: Chinese text searchable via LIKE-based queries
- [x] **DB-05**: Category/section column indexed for fast filtering

### MCP Server

- [x] **MCP-01**: MCP tool for exact function name lookup returning full documentation
- [x] **MCP-02**: MCP tool for keyword search across all API docs
- [x] **MCP-03**: MCP tool for filtering docs by API category/section
- [x] **MCP-04**: MCP tool for section-scoped search (search within a specific API section)
- [x] **MCP-05**: All responses are structured, token-efficient, with clear not-found signals
- [x] **MCP-06**: Database opened read-only, no mutations exposed

## v2 Requirements

### Strategy Generation

- **GEN-01**: User can describe a strategy in natural language and receive a generated JoinQuant Python strategy file
- **GEN-02**: Strategy generation uses stored API docs and strategy examples as context for OpenAI API calls
- **GEN-03**: Generated strategy code follows JoinQuant coding conventions observed in scraped strategies

### Extended Coverage

- **EXT-01**: Scrape additional JoinQuant API sections (期货、期权、指数 etc)
- **EXT-02**: Strategy examples searchable via MCP (not just API docs)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Real-time sync with JoinQuant | Risk of account ban; API docs are stable; manual re-scrape sufficient |
| Semantic/vector search | FTS5/LIKE sufficient for structured API docs with known terminology |
| Web UI for browsing docs | Consumer is AI models, not humans |
| Multi-user auth on MCP | Local stdio server on developer's machine |
| Automatic schema migration | DB is a disposable cache; drop and rebuild on schema change |
| Mobile app | Not relevant to the use case |
